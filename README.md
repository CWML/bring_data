# Bring Your Data: Hands-On Introduction to Data Preparation and Coding

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/CWML/bring_data/blob/main/mi_trends.ipynb)

Have a dataset but not sure where to start? Or no dataset yet? Either way, we'd love to have you! Join us for a hands-on, beginner-friendly coding session led by library staff. In this interactive workshop, participants will get practical experience importing, inspecting, and cleaning data in preparation for statistical analysis. We'll cover foundational coding concepts, explore troubleshooting strategies, and leverage AI-assisted tools available through Yale's Clarity Platform. Bring your own data to work with, or follow along using our provided demo dataset. Whether you're just starting out or have some coding experience, this session is designed to meet you where you are.

Learning Objectives: By the end of this session, participants will be able to:

    Import datasets into Python or R for analysis
    Audit and inspect data for quality and consistency issues
    Apply basic data cleaning techniques to prepare data for statistical analysis
    Use foundational coding concepts to write and understand basic scripts
    Utilize AI tools via Yale's Clarity Platform to troubleshoot coding challenges

Optional – Technical Requirements:

    Bring your own laptop
    Bring your own dataset (any format welcome)
    Python and/or R installed (instructions will be provided upon registration)
    Access to Yale's Clarity Platform
